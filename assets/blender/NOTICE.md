# Character source attribution

The weighted humanoid topology was adapted from **Quaternius — Universal Base Characters, Standard**, downloaded on 13 September 2026 from the creator's free Standard download.

- Creator: https://quaternius.com
- Pack: https://quaternius.com/packs/universalbasecharacters.html
- Download: https://quaternius.itch.io/universal-base-characters
- Source model: `Base Characters/Godot - UE/Superhero_Male_FullBody.gltf`
- The downloaded archive includes `License_Standard.txt`, specifying **CC0 1.0**. Its unmodified text is preserved in `LICENSE-Quaternius.txt`.

The original poker adaptation changes proportions, garment surfaces, facial topology, shape keys, complexion colours, hair, facial hair, clothing details, glasses and fitted headwear. Quaternius is the source of the humanoid base; this project does not claim original authorship of that base. Reference photos guide likeness and are not used as face textures.

The downloaded archive and extracted vendor directory are local modeling inputs, excluded from version control. The `.blend` files contain editable versions of the adapted geometry and skeleton. Assets under `public/models/club/` retain the shared weighted body and original Blender head variants.

The later generated-character workflow continues to use this licensed continuous body and skeleton, including the tailored Juan body exported under `public/models/tripo/`. Generated cartoon heads, supplied models and reference images have separate provenance documented in [`../tripo/NOTICE.md`](../tripo/NOTICE.md). The Quaternius CC0 license applies to the pack's contribution; it does not assign that license to unrelated supplied or generated assets.
