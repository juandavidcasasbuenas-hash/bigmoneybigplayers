## Model conversion

These images are subsequently passed to the project's existing `scripts/generate-head.ts` workflow. The script keeps a request receipt and resumes it on rerun; reuse the existing receipt rather than submitting duplicate conversions.

```sh
npx tsx scripts/generate-head.ts jack public/characters/jack-reference.png
npx tsx scripts/generate-head.ts clive public/characters/clive-reference.png
npx tsx scripts/generate-head.ts doug public/characters/doug-reference.png
```

Prompts improve reproducibility of intent, but generated pixels and inferred 3D geometry are not deterministic. Inspect every output before integrating it into the avatar manifest.
